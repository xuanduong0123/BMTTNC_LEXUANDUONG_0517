📖 Giải thích quy trình mã hóa lai ghép RSA-AES

1. Tạo RSA Key Pair: Server và mỗi client tạo cặp khóa RSA (2048-bit) - khóa công khai và khóa riêng tư.

2. Trao đổi Public Key: Server và các client trao đổi khóa công khai RSA với nhau.

3. Tạo và mã hóa AES Key: Server tạo một AES key (256-bit) CHUNG cho tất cả clients, sau đó mã hóa AES key này bằng RSA public key của từng client và gửi riêng cho mỗi client.

4. Chat an toàn: Mỗi client giải mã AES key bằng RSA private key của mình. Tất cả clients dùng CHUNG một AES key để mã hóa/giải mã tin nhắn.

📡 Server Log: Server hiển thị tin nhắn đã mã hóa (ciphertext) nhận được từ mỗi client, chứng minh dữ liệu được bảo vệ trên đường truyền.
